\doxysubsection{Detailed Description}
The functions that the listener is listening to are stored in a vector of shared\+\_\+ptr$<$void$>$. This type erasure has the advantage that we can listen to different function signatures and the \mbox{\hyperlink{a02350}{Listener}} not being a template. This works, because the deleter of the stored objects is not bound to the type information and thus there are no memory leaks possible.
