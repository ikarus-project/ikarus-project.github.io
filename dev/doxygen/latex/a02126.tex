\doxysubsection{Detailed Description}
\subsubsection*{template$<$typename F, typename LS, typename UF, typename IDBCF$>$\newline
class Ikarus\+::\+Newton\+Raphson\+With\+Subsidiary\+Function$<$ F, LS, UF, IDBCF $>$}
This class provides a Newton-\/\+Raphson solver for solving nonlinear systems with a subsidiary function. It uses a linear solver to handle the linear system arising in each iteration.


\begin{DoxyTemplParams}{Template Parameters}
{\em F} & Type of the function. \\
\hline
{\em LS} & Type of the linear solver used internally (default is Solver\+Default). \\
\hline
{\em UF} & Type of the update function (default is Update\+Default). \\
\hline
{\em IDBCF} & Type of the force function to handle inhomogeneous Dirichlet BCs (defaults to IDBCForce\+Default). \\
